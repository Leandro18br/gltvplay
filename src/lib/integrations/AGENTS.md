## Integration rules
- MegaEmbed URLs are built from admin-editable templates in site_settings by `src/lib/integrations/megaembed.ts` and saved as ordinary embed sources. Why: reuse existing source priority, authorization and player.
- M3U lists (`src/lib/integrations/m3u*.ts`): full list URL lives only in service-role `m3u_list_secrets`; Sincronizar only INDEXES the list into service-role `m3u_items` via short, checkpointed server steps (byte offset + Range when supported, batched upserts, chunked finalize RPCs under the 8s statement timeout); the main catalog changes only through explicit admin import of selected items (few per request, dedupe TMDB → item.content_id → title+year → season/episode → stream URL), producing ordinary `playback_sources` tagged `m3u_list_id`, flagged `unavailable_since` instead of deleted. Why: a single-request sync exceeded the worker CPU limit on 100k+ lists, and the public site must only show deliberately imported content.
