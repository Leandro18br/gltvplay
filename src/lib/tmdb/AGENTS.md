- Episode covers: "Atualizar episódios" replaces missing/HTTP/malformed/wrong-episode TMDB stills matched by series TMDB id + season + episode number, keeping custom HTTPS images; displays pass URLs through `safeImageUrl`. Why: HTTP stills are blocked on the HTTPS site.
- Credits/videos/extra fields: `apply_tmdb_extras` (staff RPC) fills empty columns only and upserts `content_credits`/`content_videos` keyed by TMDB credit/video id; trailer choice in `extras.ts` (Trailer type only, pt-BR official first) and never touches playback. Genre completion never creates genres. Why: idempotent re-runs and fixed genres.
- `enrichContent` is the single fill-only enrichment for every movie/series path (manual TMDB import, BugouMods, extension, worker, recovery); it also runs when cast/trailer are missing and returns filled/incomplete/unmatched with remaining gaps. Why: movies previously skipped extras.
